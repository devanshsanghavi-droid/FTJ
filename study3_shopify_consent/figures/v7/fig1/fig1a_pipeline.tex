% Figure 1a (v7; binding spec ../DESIGN_V7.md, sections 6-7; this file is the worked example of a v7 schematic):
% where consent is lost. The sciplot schematic rules re-implemented in TikZ (never executed), plus the bake-off grafts.
% Message: the CMP's script blocker walls off the page only; Shopify's consent gate starts the pixels in sandboxes
% whose requests leave the browser for the ad vendors underneath the wall.
%
% Nested regions (FigGenie; three levels at most: region > region > box), each labelled at its top-left in the muted
% 7 pt container style:
%   level 1  'Shopify store in the browser': an outline-only frame (0.6 pt NEUTRAL) around everything that runs in the
%            visitor's browser -- the consent signals, the page, Shopify's consent gate and the pixel sandboxes. The ad
%            vendors stand outside it, so the brick requests visibly LEAVE the browser;
%   level 2  'Page (main thread)' (TINT PAGE ground, NEUTRAL outline) and 'Pixel sandboxes' (TINT SAND ground, SAND
%            outline): one step apart in lightness, the same two grounds as panel b's two lanes;
%   level 3  the element boxes: white, 0.6 pt SPAXIS, sized to their text with 2.4 x 1.6 mm padding (sciplot S.box),
%            corners 0.5 mm; the cookie banner is the one tinted box (TINT EVENT: its appearance is the amber rule of b
%            and c).
% Columns: x = 62 the cookie banner above Shopify's consent gate (the CMP's choice runs straight down into it);
% x = 108 the vendor tags (page) above the pixel sandboxes (the same vendors' code, isolated) -- b's two lanes;
% x = 141 the script blocker, a solid wall over the page region only; x = 169.5-187.5 the ad vendors, outside the browser.
% Connectors 0.6 pt stopping 0.6 mm short; the one accent is the two leak paths (LEAK, 1.0 pt = the data weight) and the
% dotted grey hairline is the path the wall cuts (the only broken line in the figure: one meaning).
% The ad-vendor box holds the vendor groups used in every figure (figstyle.VENDOR_ORDER; asserted in
% scripts/make_panels.py) in 6 pt muted grey: grey, never vendor hues (brick is in this panel).
% Loss numerals (DESIGN_V7 section 7.4): \lossno{x,y}{n} draws a small outlined ring (2.7 mm, 0.5 pt LEAK, white inside)
% with a 6 pt SPFG digit at the five points where consent is lost, in the caption's order: 1 the region default (on its
% arrow), 2 the script blocker (beside the wall), 3 the CMP's choice (on its arrow), 4 the consent gate (its top-right
% corner), 5 the path to the vendors (between the leak paths, just outside the browser). They are the only digits in
% the panel (make_panels.check_composite and trace_fig1.py enforce it); the counts live in the caption.
% Colours: ../style/palette_v2.tex (SP* = sciplot clean theme, TINT* = pre-mixed token tints). Cell: 190 x 44 mm
% (= fig1.tex, asserted in scripts/make_panels.py).
\documentclass[tikz,border=0pt]{standalone}
\def\StyleDir{../style/}
\input{\StyleDir tikzstyle_v2.tex}
\tikzset{
  every node/.append style={text=SPFG},
  el/.style={draw=SPAXIS, fill=surface, line width=0.6bp, rounded corners=0.5mm, inner xsep=2.4mm, inner ysep=1.6mm,
             minimum height=6mm, font=\fsLabel, align=center, anchor=center},
  el banner/.style={el, draw=EVENT, fill=TINTEVENT},
  el sbx/.style={el, minimum width=33mm},
  region browser/.style={draw=NEUTRAL, fill=none, line width=0.6bp, rounded corners=0.5mm},
  region page/.style={draw=NEUTRAL, fill=TINTPAGE, line width=0.6bp, rounded corners=0.5mm},
  region sbx/.style={draw=SAND, fill=TINTSAND, line width=0.6bp, rounded corners=0.5mm},
  regionlbl/.style={font=\fsLabel, text=SPMUTED, inner sep=0pt, anchor=base west},
  t/.style={font=\fsLabel, inner sep=0pt},
  sub/.style={font=\fsNote, text=SPMUTED, inner sep=0pt},
  con/.style={-{Stealth[length=3.4bp, width=2.8bp, inset=0.9bp]}, draw=SPAXIS, line width=0.6bp, rounded corners=0.8mm},
  conplain/.style={draw=SPAXIS, line width=0.6bp, rounded corners=0.8mm},
  leakarr/.style={-{Stealth[length=4.25bp, width=3.4bp, inset=1.2bp]}, draw=LEAK, line width=1bp},
  wire/.style={draw=NEUTRAL, line width=0.8bp, line cap=butt},
  wall/.style={fill=SPFG, draw=none, rounded corners=0.25mm},
  lossring/.style={circle, draw=LEAK, line width=0.5bp, fill=surface, minimum size=2.7mm, inner sep=0pt,
                   font=\fsNumeral, text=SPFG},
}
% \lossno{x,y}{n}: loss numeral n centred at (x,y) mm -- an outlined ring, never a filled disc
\newcommand{\lossno}[2]{\node[lossring] at (#1) {#2};}
